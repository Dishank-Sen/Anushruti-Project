# Adding educational content

Add a typed lesson to `lib/lessons.ts`. Each lesson needs a unique stable ID, class (1–5), Maths/Science subject, short title, learning objective, estimated minutes, visual steps, and a multiple-choice question with helpful feedback.

Each step pairs a diagram/symbol sequence with a complete text explanation. Do not rely on a colour, sound, symbol or long sentence alone. Give examples before questions, keep controls in the same place and allow repetition without penalty. There are no timers or forced voice responses.

Content supplied in this repository is illustrative and requires curriculum and deaf-educator review before classroom use. The sample lessons are not a complete syllabus. Sign-language and speech practice are intentionally not simulated. Future communication activities should remain optional, include text/sign alternatives, and avoid judging a child by speech production.

For video extensions include a locally or remotely hosted asset URL, language, captions (WebVTT), transcript, duration, media licence and attribution, and the name/date of a qualified reviewer. Never publish an unreviewed clip as ISL. Use a native caption-capable player and track video completion separately from visual lesson completion. Do not reuse videos merely because they are publicly viewable.

A content PR must explain the learning goal, age suitability, source/permission, answer rationale, accessibility behavior, and specialist review requested. Validate IDs and answers with the test suite.
